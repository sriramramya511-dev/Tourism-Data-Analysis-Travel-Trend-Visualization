# Tourism Data Visualization

## Project Overview

This project explores tourism data using graphs created with Python. The
visualizations summarize international tourist arrivals, tourism
receipts, tourism expenditures, and regional arrivals from 2015 to 2025.

## Dataset

-   **File:** `Original_and_Cleaned_Tourism_Data-1.xlsx`
-   **Sheet used:** `Cleaned Data`
-   **Records:** 77
-   **Regions:** 7
-   **Years covered:** 2015--2025

## Visualizations

1.  **Total International Tourist Arrivals by Year** --- shows the
    yearly trend in tourist arrivals across all regions.
2.  **Tourism Receipts vs Expenditures by Year** --- compares tourism
    receipts and expenditures over time.
3.  **Cumulative International Arrivals by Region** --- compares total
    recorded arrivals across regions for the full period.

## Tools and Libraries

-   Python
-   pandas
-   matplotlib
-   openpyxl

Install the libraries with:

``` bash
pip install pandas matplotlib openpyxl
```

## How to Run the Python Script

1.  Place the Excel dataset and Python script in the same folder.
2.  Make sure the worksheet is named `Cleaned Data`.
3.  Run the script using Python.
4.  The graphs will appear one at a time.

## Data Quality Note

In the supplied workbook, the `Original Data` and `Cleaned Data` sheets
contain identical data. The `Cleaned Data` sheet has no missing cells,
so the workbook does not show visible changes from data cleaning.

## Output

The PDF `Tourism_Visualization_Graphs_Only.pdf` contains the three
graphs without the Python code.
